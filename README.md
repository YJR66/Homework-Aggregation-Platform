# 作业聚合系统

在本机读取学习通、雨课堂、PTA 和希冀平台的作业，汇总为统一清单。希冀是校内平台，当前已适配东北大学秦皇岛分校的统一身份认证与 WebVPN。系统只读取课程/作业列表，不答题、不交卷、不修改平台作业。

## 启动

环境：Windows、Node.js 22+、Chrome 或 Edge。

双击 **启动.cmd**，或在项目目录执行：

```powershell
npm ci
npm start
```

打开 <http://127.0.0.1:4317>。只监听本机地址，不公开到局域网或互联网。

双击 **停止.cmd** 会先保存登录态再停止服务；终端运行时也可以按 `Ctrl+C`。

## 使用

1. 在平台卡片点击「账号密码登录」，输入该平台账号和密码。希冀需分别填写平台账号密码、学校统一身份认证账号密码；已适配学校的入口地址内置，无需手动填写。
2. 点击「保存并登录」后，凭据在本机加密保存，系统自动尝试登录；登录成功后自动读取作业。已有有效会话会直接复用，不重复提交密码；之后可点击「已保存账号登录」重新尝试。希冀依次完成学校统一认证和平台登录，不反复提交错误密码。
3. 每个平台独立显示**登录状态、最近验证时间和作业采集状态**。遇到无法自动完成的验证时点击「人工辅助」，完成后可使用已保存账号重新登录和读取作业。也可使用「读取作业」或「同步全部」；同步全部时四个平台使用独立浏览器会话并行读取，单个平台失败不会取消其他平台。
4. 可以搜索、按平台筛选、按截止日期排序、导出 `.ics` 日历；清单勾选只会发起一次平台只读确认，不会直接标记本地完成。
5. 服务运行期间默认每 30 分钟同步；设置可修改为 5～1440 分钟。电脑关机或服务停止时不会同步。

### 邮件提醒

在侧栏打开「邮件提醒」，填写 SMTP 主机、端口、加密方式、账号、密码或授权码，以及发件和收件地址；保存后可发送一封不含作业信息的测试邮件。支持 SSL/TLS（通常为 465 端口）和强制 STARTTLS（通常为 587 端口）。SMTP 密码使用当前 Windows 用户的 DPAPI 加密，页面与 API 不回显密码。实际端口和授权方式以邮件服务商提供的配置为准。

可添加最多 12 条提醒规则：设置**截止前或截止后**多少分钟、小时或天发送，并选择全部平台或指定平台。规则只对启用后尚未到达的时间点生效；服务暂停期间错过的提醒，会在恢复后且作业状态仍新鲜时补发。同一作业、截止时间、规则和收件地址成功发送一次后不重复发；截止时间发生变化时可重新提醒。多项同时触发会合并为一封邮件。

邮件只依据最近一次平台读取结果：只提醒有截止时间、仍显示未完成、未从列表消失，并且在「状态时效」内重新读取过的作业。已提交/已完成、状态读取失败、已失去来源或超过时效的记录不会作为“未完成”发信。邮件会注明最近读取时间，**不会附带可能含临时凭据的平台链接**。请保持本机服务与自动同步运行；关机时不能准时发信。SMTP 服务器接受邮件不等于收件箱已实际投递，首次配置后建议检查测试邮件。

只有平台云端明确返回已提交或已完成，任务才会归入已完成；勾选清单不会向平台提交答案。每项可展开「状态依据」查看个人记录。状态区分未开始、进行中、已提交和课件阅读完成，逐题提交数量与通过数量分开统计。只有详情实际读取失败才显示失败原因，不把失败当成未提交。同步失败/部分读取不等于没有作业，旧清单不会被清空。

已完整扫描的当前列表中不再出现的旧任务，会标注「本轮未再显示，请到原平台确认」，不会擅自认定为已交或删除。

### 本地验证码识别

希冀登录页的图片字符验证码支持本地 OCR。首次使用可在项目目录执行：

```powershell
npm run setup:ocr
```

平台面板会显示本地 OCR 是否就绪。验证码图片仅在本机内存中识别，不保存为图片文件、不上传到第三方；识别置信度不足或图片刷新时不会盲填。当前支持的是已适配的**图片字符验证码**，不是所有验证方式：短信、扫码、滑块、点选及无法可靠识别的图片仍可能需要一次人工操作。组件未就绪时也可使用「人工辅助」，不影响已有效登录的会话同步。

登录状态与作业采集分开判断：`authenticated` 表示最近一次只读验证通过，`expired` 表示登录过期，`challenge` 表示需要补充验证，`invalid_credentials` 表示账号或密码错误，`authenticating` 表示正在登录或验证，`unknown` 表示尚未验证。作业的「部分读取」不等于未登录；登录成功也不代表所有作业明细已读取完成。

## 数据与账号

- `data/credentials.dpapi.json`：Windows 当前用户 DPAPI 加密凭据；源码不含账号密码，API 不返回密码。
- `data/session-*.dpapi`：DPAPI 加密 cookies，用于保留 session cookies；localStorage 由本机独立 profile 保存，不在导航时重放旧 token。
- `data/profiles/`：每个平台独立 Chromium 登录环境，属于敏感本地数据。
- `data/state.json`：作业清单、同步状态和设置，采用原子写入。
- 邮件地址、规则、发送去重记录保存在 `data/state.json`；SMTP 密码/授权码保存在 `data/credentials.dpapi.json`，不会写进源码仓库。
- `data/`、`.playwright-cli/` 和 `output/` 均排除在 Git 之外，不应作为源码分享。
- 当前工作区绑定一组账号；更换账号应使用独立工作区，避免旧账号登录态/作业混入。
- DPAPI 文件只能由当前 Windows 用户解密；拷贝到其他电脑后需要重新配置和登录。

## 读取范围

平台接口与页面会变化。连接器只使用已验证的只读页面或页面原生响应；结构不匹配时显示「部分读取」，不会用猜测式通用扫描冒充完整结果。

PTA 的个人活跃题目集与公开题库分开：只收录个人已开放题目集，未开放项不加入当前清单。列表总数核对后，继续读取个人概览页面实际返回的答题实例、题型总数和逐题提交状态；等待页面异步接口完成，临时缺失时最多重载一次，不点击开始答题、继续答题或交卷。没有开始的题目集能明确显示未开始，但平台尚未开放的题数不编造。客观题已提交不代表答对。

希冀的普通作业按题目核对个人提交记录；单选题的延迟渲染资源必须能绑定到当前作业的个人答案表单，才只读解析已保存选项。练习使用平台个人练习概览，核对各题型完成数之和与总题数，展示“已完成题数 / 总题数”，不将练习进度冒充提交次数。登录失效返回空白主页时，只读回到已知登录入口重新核验。

目前已通过真实登录与只读页面验证的适配范围：

| 平台 | 范围 | 关键语义 |
| --- | --- | --- |
| 学习通 | 我学的课中未结课课程 → 作业，按每课总数核对 | 已完成/待批阅归已提交；仅倒计时的截止时间显示“约”，不是精确时刻 |
| 雨课堂 | 我听的课 → 未完成任务与个人阅读进度；历史课件从未完成列表消失时复核学习内容目录 | 区分需交答案的作业与作业相关课件，展示具体已读页数；不打开课件刷阅读进度 |
| PTA | 个人活跃题目集 → 个人概览 → 页面原生返回的逐题提交记录 | 核对题数、提交数、编程题通过数；需要最终交卷时不将答完题冒充已交卷 |
| 希冀 | 学校 CAS → WebVPN → 希冀 → 当前作业明细与个人练习概览 | 客观题核验服务器保存表单及其绑定资源，练习核对个人完成进度；不执行答题表单脚本，不填写或提交答案 |

“已连接”表示上述范围完成读取，不表示平台中所有历史任务、考试或学习活动都已覆盖。

## 开发与测试

```powershell
npm test
npm run check
```

架构：`server/index.mjs` 本地 HTTP API/并发同步调度，`server/browser.mjs` 登录与隔离会话，`server/connectors.mjs` 平台分派，`server/{chaoxing,yuketang,pta,xiji}.mjs` 各平台只读采集器，`server/parsers.mjs` 日期/状态解析，`server/reminders.mjs` 邮件规则判断，`server/mailer.mjs` SMTP 发送，`server/store.mjs` 持久化与日历，`server/vault.mjs` 凭据加密，`public/` 原生前端。没有前端构建步骤或云端服务。

修改连接器时，先更新相应的 `tests/*.test.mjs` 离线页面/响应夹具，再运行上述两项命令。读取不完整时必须保留失败或部分读取状态，不能用本地勾选、课件浏览或页面装饰信息推断云端提交。

可用环境变量：`PORT` 指定端口；`HOMEWORK_BROWSER_PATH` 指定 Chrome/Edge 可执行文件。启动脚本使用默认端口 4317。

## 常见情况

- **登录失败**：检查卡片中的独立登录结果。账号或密码错误时，点击「账号密码登录」重新输入，保存后自动重试；不会将登录请求已发出当成成功。
- **需要重新验证**：登录过期可点击「已保存账号登录」，也可重新填写账号密码；希冀图片字符验证码可本机识别，短信、扫码、滑块或点选等使用「人工辅助」完成。
- **本地 OCR 未就绪**：运行 `npm run setup:ocr` 安装本地识别组件，再重新启动服务；也可直接使用人工辅助。图片识别只在本机处理，不外传。
- **网络切换 / 课程目录加载失败**：学习通、雨课堂的只读导航对瞬时网络错误最多尝试 3 次，目录加载异常可额外重载一次。只有明确登录页面才提示重新验证；临时失败保留旧清单，后续自动同步仍会尝试。卡片的更新时间保留为最近一次完整同步成功时间。
- **浏览器启动失败**：关闭占用同一项目 profile 的其他调试进程，再重试。
- **部分读取 / 0 条**：查看平台卡片消息，并在原平台确认，不能将它解读为没有作业。
- **浏览器关闭后的登录态**：系统每 20 秒及正常停止前加密保存会话；刚登录即强制杀进程可能来不及保存。
- **非 Windows**：清单服务代码可运行，但自动保存凭据依赖 Windows DPAPI；本项目以 Windows 为验证环境。
